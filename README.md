# Replica-Synchronized Randomized Measurements

Theory-and-simulation research code and generated data for local purity
estimation under non-i.i.d. quantum sources. No hardware experiment or
universal superiority is claimed.

## Install and check the supplied results

Tested with Python 3.12.14. From the repository root:

```bash
python -m venv .venv
# Linux/macOS: source .venv/bin/activate
# Windows PowerShell: .\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python restore_data.py
python -m unittest -v
python verify_phase3.py
python verify_phase4.py
```

`restore_data.py` decompresses frozen CSVs and verifies their original SHA-256
digests. It refuses to overwrite a locally modified CSV. JSON summaries are
included directly. See `DATA.md` and `DATA_MANIFEST.json`.

## What the data mean

There are no third-party datasets to download. Density matrices, source
trajectories and Born-rule outcomes are generated by the supplied scripts with
recorded seeds. The included CSVs are estimator-level simulation records and
analysis artifacts; they are **not a complete archive of every measurement
bit string**, nor experimental-device observations. Shot-level records can be
resimulated using the recorded source-generation and measurement seeds.

The primary benchmark contains 1440 design tasks and 220800
method--subsystem result records. Record count is not the number of independent
datasets or physical measurements. Independent reconstruction checks use new
seeds and must not be substituted with earlier reported values.

## Regenerate instead of using frozen outputs

```bash
python reproduce.py --stage quick       # Unit tests and small analytic tables
python reproduce.py --stage core        # Full matched-copy, boundary, mismatch, readout
python reproduce.py --stage online      # Selector development and held-out suites
python reproduce.py --stage validation  # Requires core outputs
```

For all stages including early diagnostics: `python reproduce.py --stage all`.
These stages regenerate output files; retain a clean copy of frozen data if
you want to compare them. Full simulations are CPU-intensive; several scripts
use four processes. The runner limits BLAS threads per worker to one. No GPU
is required. No full-runtime estimate is asserted.

## Components

- `local_protocol.py`: quantum state generation, sampling and local estimators.
- `baseline_protocols.py`: temporal, Bell/SWAP and randomized-measurement comparators.
- `phase3_theory.py`: temporal dispersion, mismatch and selection helpers.
- `online_selector.py`: frozen selector.
- `run_*.py`: simulation studies; `analyze_phase3_boundary.py`: calibration-only analysis.
- `rebuild_validation.py`: feedback, independent-bank and adjusted inference checks.
- `minimax_benchmark.py`: corrected general-state and product-pure risk bounds.
- `make*_figures.py`: figure regeneration; `test_*.py` and `verify_*.py`: checks.

The general-state variance bound is `3**k-3/4`; the product-pure exact variance
is `3**k-1`. Copy thresholds use strict inequality and integer paired budgets.
