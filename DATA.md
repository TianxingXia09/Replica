# Data provenance and files

All supplied data were generated by numerical simulation, not downloaded from
an external benchmark. The data are part of this study's computational record.
The code simulates density matrices on three to five qubits and local
measurement outcomes. The locality-scaling check samples an exact local law;
it is not a dense simulation of a 64-qubit state.

Frozen CSVs are compressed individually as `.csv.gz`; JSON summaries are
included directly. Run `python restore_data.py` before using the existing
data-dependent analysis or verification scripts. `DATA_MANIFEST.json` records
each uncompressed path, original byte count and SHA-256 digest.

| Folder | Contents | Generation |
|---|---|---|
| `phase2_results/` | Matched-copy benchmark, timings and comparisons | `run_phase2_benchmarks.py` |
| `phase3_results/` | Calibration boundary, dispersion and mismatch outputs | `analyze_phase3_boundary.py`, `run_phase3_mismatch.py` |
| `online_pilot_results/` | Selector development records | `run_online_selector_pilot.py`, `finalize_online_development.py` |
| `online_results/` | 512-round selector suite | `run_online_selector_benchmark.py` |
| `online_large_results/` | 2000-round selector suite | `run_online_largeblock_benchmark.py` |
| `readout_results/` | Symmetric readout-noise study | `run_readout_stress.py` |
| `minimax_results/` | Corrected risk bounds and integer-copy budgets | `minimax_benchmark.py` |
| `rebuild_results/` | Freshly seeded reconstruction checks | `rebuild_validation.py` |

The tables called `raw.csv` contain estimator-level simulation outputs
(truth, estimates, errors and design identifiers), not every underlying shot.
Measurement settings and bit strings are generated transiently by the code.
State banks and trajectories can be regenerated from the recorded seeds.

The earlier `results/` and `local_results/` diagnostic outputs are not bundled:
they can be regenerated by `run_falsification.py` and `run_local_stress.py` and
are not needed by the main manuscript-result verifiers.

No private Drive URL, fabricated dataset DOI or unrelated classification
dataset is presented as a public data source. Until an actual repository or
archival DOI is published, readers receive this bundle through the manuscript's
computational supplement.
